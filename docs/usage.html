基本操作とショートカット

画面の見方とキーボード操作です。

画面構成

┌──────────────────────────────────────────────┐ │ [タブ1 ●] [タブ2 (3)] [+] ─ □ ✕ │ ← タブ行 ├──────────────────────────────────────────────┤ │ ← → ⟳ │ https://x.com/home │ −100%＋ ◐ ⚙ │ ← ツールバー ├──────────────────────────────────────────────┤ │ │ │ ページ表示領域 │ │ │ └──────────────────────────────────────────────┘
  • タブの (3) のような赤いバッジは未読件数です。
  • タブ左の色つきの点は、そのタブのプロファイルの色です (既定プロファイルには付きません)。
  • ツールバー右側は、縮小 / 拡大率 / 拡大、テーマ切替、設定ボタンです。

キーボードショートカット

キー動作
Ctrl + Lアドレスバーにフォーカス (全選択)
Ctrl + ,設定タブを開く
Ctrl + Shift + Dダーク / ライトを切り替え
Ctrl + + / -拡大 / 縮小
Ctrl + 0拡大率を 100% に戻す
Ctrl + ホイール拡大 / 縮小
Esc (アドレスバー内)入力を破棄して元の URL に戻し、ページへフォーカス

タブ操作

  • 追加: タブバーの「+」、または右クリックメニューの「新しいタブ」
  • 並び替え: タブをドラッグ。数ピクセル動かすまではクリック扱いなので、誤って入れ替わりません
  • 閉じる: タブの「×」、または右クリックメニュー

右クリックメニュー

タブバー上 (タブや余白) を右クリックすると、新しいタブ、プロファイル別の新しいタブ、このタブを閉じる、設定、スタートページ、拡大率のリセットが出ます。ページ内の右クリックは WebView2 標準のメニューです。

通知

X からのデスクトップ通知を許可するかどうかを、設定の「通知」で切り替えられます。
