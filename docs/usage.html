基本操作とショートカット

画面の見方とキーボード操作です。

画面構成

┌──────────────────────────────────────────────┐ │ [タブ1 ●] [タブ2 (3)] [+] ─ □ ✕ │ ← タブ行 ├──────────────────────────────────────────────┤ │ ← → ⟳ │ https://x.com/home │ −100%＋ ◐ ⚙ │ ← ツールバー ├──────────────────────────────────────────────┤ │ │ │ ページ表示領域 │ │ │ └──────────────────────────────────────────────┘
  • タブの (3) のような赤いバッジは未読件数です。
  • タブ左の色つきの点は、そのタブのプロファイルの色です (既定プロファイルには付きません)。
  • ツールバー右側は、縮小 / 拡大率 / 拡大、テーマ切替、設定ボタンです。

タブ操作

  • 追加: タブバーの「+」、または右クリックメニューの「新しいタブ」
  • 並び替え: タブをドラッグ。数ピクセル動かすまではクリック扱いなので、誤って入れ替わりません
  • 閉じる: タブの「×」、または右クリックメニュー

X のリンクをアプリで開く

  • ページ内で新しいタブを開く操作 (target="_blank"、window.open、中クリック、Ctrl / Shift + クリック) で開く X のリンクは、同じプロファイルの新しいタブで開きます。X 以外の URL は従来どおり既定のブラウザーで開きます。
  • ショートカットから開くときは、リンク先を "C:\...\xbrowser.exe" https://x.com/notifications のように、起動引数に URL を付けて指定します。x.com/foo のようにスキームを省いても使えます。
  • すでに起動しているときは、新しいウィンドウを作らず、起動中のアプリに新しいタブとして渡して前面に出します。
  • X のドメイン以外の引数は無視します。一度に開けるタブは 40 個までです。

他のブラウザーの「X で共有」を受ける

Windows は x.com のリンクだけを特定のアプリで開かせることができません。そのため、アプリが xbrowser:// を受け付け、付属のブラウザー拡張機能が共有ボタン (x.com/intent/post など) を xbrowser://share?... に切り替える、という組み合わせにしています。

  1. 設定 → 一般 → 「他のブラウザーからの共有」をオンにします。現在のユーザーにだけ登録し、管理者権限は不要です。オフにすると削除します。アプリの場所を移動したときは、オフ → オンでやり直してください。
  2. 配布物の extension フォルダを、他のブラウザーに読み込みます。
    • Chrome / Edge: chrome://extensions (Edge は edge://extensions) で「デベロッパー モード」をオン → 「パッケージ化されていない拡張機能を読み込む」
    • Firefox: about:debugging → 「このFirefox」 → 「一時的なアドオンを読み込む」 (再起動すると外れます)
  3. 共有ボタンを押すと、ブラウザーの確認 (「常に許可」で省略可) のあと XBrowser が前面に出て、text / url / hashtags / via などが入った投稿画面を新しいタブで開きます。

手動でも xbrowser://share?text=こんにちは&url=https%3A%2F%2Fexample.com や xbrowser://open?url=https%3A%2F%2Fx.com%2Fhome で開けます。投稿画面を開くだけなので、「ポスト」ボタンは自分で押します。

拡張機能が見る範囲対象は x.com / twitter.com の /intent/post・/intent/tweet・/share だけで、通信は行いません。必要な権限はページ移動の検知 (webNavigation) だけです。

翻訳

  • ページ内でテキストを選択して右クリックすると、「コピー / 翻訳」のメニューが出ます。
  • 選択せずにポスト本文の上で右クリックしたときは、そのポスト全体が対象です。
  • 「翻訳」を選ぶとその場にポップアップが出て、翻訳結果を表示します。「コピー」で結果をコピーでき、「Google翻訳で開く」で既定のブラウザーに切り替えられます。×・Esc・ほかの場所のクリックで閉じます。翻訳先はアプリの表示言語、翻訳元は自動判定です。
  • 入力欄の中の右クリックは、WebView2 標準のメニューのままです。
  • テキストを選択した状態でタブバーを右クリックしても、「選択中のテキストを翻訳」が出ます (ページ上部中央にポップアップ)。
送信される内容翻訳を選ぶと、選んだテキスト (最大 1500 文字) がアプリから Google の翻訳サーバーに送られます。

タブバーの右クリックメニュー

X のメニューに近い、丸みのある配色・太めの文字・アイコンで表示します (ダーク / ライトはアプリのテーマに連動)。

タブバー上 (タブや余白) を右クリックすると、新しいタブ、プロファイル別の新しいタブ、このタブを閉じる、設定、スタートページ、拡大率のリセットが出ます。ページ内の右クリックは WebView2 標準のメニューです。

通知

X からのデスクトップ通知を許可するかどうかを、設定の「通知」で切り替えられます。
