config.json リファレンス

%LocalAppData%\XBrowser\config.json の項目です。初回起動時に自動で作られ、設定画面からの変更も自動保存されます。

{
  "zoom": 1,
  "notifications": "on",
  "startPage": "simple",
  "language": "ja",
  "startBg": "black",
  "startImage": "",
  "themeSync": "on",
  "barScale": 100,
  "barLayout": "tabs-top",
  "profiles": ["仕事用"],
  "profileNames": {},
  "profileColors": {},
  "theme": {
    "preset": "dark",
    "tabActive": "#2F3336",
    "tabRadius": 12
  }
}
キー値説明
zoom0.25 〜 5拡大率 (1 = 100%)
notificationson / offデスクトップ通知の許可
startPagesimple / x新しいタブで開くページ
languageja / en / zh / ko など表示言語 (未設定なら OS から判定)
startBgwhite / black / imageスタートページの背景
startImageファイル名取り込んだ背景画像 (通常は設定画面から操作)
barScale80 〜 140上部バー (タブ・アドレスバー) の大きさ (%)
barLayouttabs-top / toolbar-topタブを上にするか、アドレスバーを上にするか
themeSyncon / offX の画面にもテーマを反映
profiles文字列の配列追加したプロファイルの ID
profileNamesID → 表示名プロファイルの表示名
profileColorsID → #RRGGBBプロファイルの色

theme

キー説明
presetdark / light / system
barBackground tabActive tabInactive tabHoverバーとタブの背景色
tabText tabTextInactiveタブの文字色
icon buttonHover closeHover closeHoverIconアイコンとボタンの色
tabRadiusタブの角の丸み (2〜24px、既定 12)

色は #RRGGBB 形式で、空文字の項目はプリセットの色が使われます。ファイルを直接編集した場合はアプリを再起動してください。

パス内容

%LocalAppData%\XBrowser\debug.logデバッグログ
