機能一覧

xbrowser で使える機能の一覧です。

ウィンドウとタブ

機能説明
カスタムタイトルバー枠なしウィンドウ。最小化/最大化/閉じるボタンは大きめの 46px 幅。端のドラッグでリサイズ、タイトルバーのダブルクリックで最大化。
起動時に最大化既定で最大化して起動します。元に戻すと画面の約 85% のサイズになります。
タブ追加・切り替え・閉じる。ドラッグ&ドロップで並び替えできます。
通知バッジ未読の通知・DM の件数を、タブの閉じるボタンの左に赤いバッジで表示 (99 件超は 99+)。
多重起動防止すでに起動している場合は新しいウィンドウを作らず、既存のウィンドウを前面に出します。

アドレスバー

タブの下の段に、戻る・進む・再読み込みと、URL の表示/入力欄があります。

入力動作
X のドメインの URL現在のタブで開く (http:// は https:// に補正)
X 以外の URL / t.co既定のブラウザーで開く
@名前x.com/名前 を開く
URL でない文字列X の検索結果を開く

外観

  • ダーク / ライト / システムに合わせる の 3 モード。ツールバーの太陽/月ボタンでも切り替え可能
  • 「X の画面にも反映」で X 側の表示設定 (night_mode クッキー) も連動 (ベストエフォート)
  • タブバーの各部の色、タブの角の丸みを設定画面から変更可能
  • 拡大・縮小 25%〜500%、設定は次回起動時も維持

スタートページ

新しいタブで開くページを「簡易スタートページ」と「X のホーム」から選べます。簡易スタートページには時計、検索ボックス、X の主要ページへのショートカットが並びます。背景は 白 / 黒 / 画像 から選べます (画像は 20MB まで、jpg / png / gif / webp / bmp)。

プロファイル

ログイン状態を完全に分けて複数アカウントを使えます (50 個まで)。名前の変更とタブ上の色の指定が可能です。詳しくはプロファイルを参照してください。

言語

設定・メニュー・スタートページを含むアプリ全体の表示言語を、日本語 / English / 简体中文 / 한국어 から選べます。初回は OS の言語から自動判定します。

翻訳

ページ内でテキストを選択して右クリックすると「コピー / 翻訳」のメニューが出ます。選択せずにポスト本文の上で右クリックすると、そのポスト全体が対象です。「翻訳」はGoogle翻訳を既定のブラウザーで開き、翻訳先はアプリの表示言語です。詳しくは基本操作を参照してください。

外部リンクの扱い

X (x.com / twitter.com / twimg.com / twimg.net) 以外のリンク、および t.co の短縮 URL は既定のブラウザーで開きます。ページに注入した JavaScript が、クリック (中クリック・Ctrl + クリックを含む) と window.open を横取りして処理します。開くのは http / https の URL だけで、file: やネットワークパス、独自プロトコルは開きません。
