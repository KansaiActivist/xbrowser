xbrowser

X (旧Twitter) 専用の軽量Windowsデスクトップアプリ。Go + WebView2 製。

xbrowser は、Windows に標準で入っている Microsoft Edge WebView2 を使って X を表示する、タブ付きの小さなデスクトップアプリです。Chromium を丸ごと同梱する Electron 系と違い、ランタイムを共有するためメモリ消費が小さく済みます。

機能一覧タブ、アドレスバー、プロファイル、テーマなど 基本操作ショートカットと画面の見方 設定画面タブとして開く X 風の設定 プロファイル複数アカウントの使い分け ビルド方法go build だけで作れます 仕組み・構成ファイルごとの役割

必要環境

  • Windows 10 / 11 (64bit)
  • Microsoft Edge WebView2 Runtime (Windows 11 やEdge搭載環境ではほぼ標準で入っています)
  • ビルドする場合: Go 1.21 以降 (CGo 不要)

特長

  • タブごとに独立した WebView2 を持ち、軽量な枠なしカスタムウィンドウで動作
  • X 以外のリンクや t.co は自動で既定のブラウザーで開く
  • プロファイルごとにログイン状態を分離し、色と名前で見分けられる
  • 日本語 / English / 简体中文 / 한국어 に対応
動作確認についてWindows 向けのビルドは確認済みですが、実機での動作確認は限定的です。アドレスバーの見た目、ドラッグ並び替えの操作感、X 側のテーマ連動や通知バッジは、X の仕様に依存する部分があります。
