トラブルシューティング

よくある症状と対処です。

画面が真っ黒 / 何も表示されない

  • タスクマネージャーで xbrowser.exe が複数動いていないか確認し、すべて終了してから 1 つだけ起動し直してください。WebView2 は同じデータフォルダを複数プロセスで使えません。
  • WebView2 Runtime が入っているか確認してください。無い場合は起動時にエラーが表示されます。
  • 改善しないときは %LocalAppData%\XBrowser\debug.log を確認してください。

タスクバーのアイコンが変わらない

ビルド方法のアイコン埋め込み手順を確認してください。.syso を置かずにビルドしていないか、debug.log の「アイコン リソース数」が 0 でないかを見ます。Windows のアイコンキャッシュが原因のときは、ピン留めを外して付け直してください。

X の画面がダーク / ライトに切り替わらない

X 側のクッキー仕様に依存する機能です。設定の「X の画面にも反映」をオフにし、X の「表示」設定で手動で切り替えてください。アプリ側のタブバーのテーマは影響を受けません。

通知バッジが出ない

バッジは X のメニューのバッジとタイトルの (N) から件数を読み取っています。X の画面構成が変わると取得できなくなることがあります。

リンクが既定のブラウザーで開かない

外部リンクはクリック・window.open に加え、ナビゲーション開始時にもネイティブで判定するため、location.href やリダイレクトでも既定のブラウザーで開きます。http / https 以外の URL は安全のため開きません。

アドレスバーに入力した文字が検索になる

ドットを含まない文字列、スペースを含む文字列、http(s) 以外のスキーム (javascript: など) は検索として扱います。ドメインは x.com/home のようにドット付きで入力してください。

設定を初期状態に戻したい

色だけなら設定の「外観」にある初期化ボタンを使います。すべて戻したい場合は、アプリを終了して config.json を削除してください (ログイン情報は WebView2Data* に残ります)。
