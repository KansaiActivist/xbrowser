設定画面

設定は X の設定画面のように、タブとして開きます。

歯車ボタン、Ctrl + ,、または右クリックメニューから開きます。すでに開いている場合はそのタブに切り替わります。変更はすぐ反映され、config.json に自動保存されます。

項目

セクションできること
一般他のブラウザーからの共有 (xbrowser:// の登録)、表示言語、新しいタブで開くページ (簡易スタートページ / X のホーム)、通知のオン/オフ
外観ダーク / ライト / システムに合わせる、「X の画面にも反映」、タブの角の丸み、上部バー (大きさ 80〜140%、配置)、各部の色、色の初期化
スタートページ背景を 白 / 黒 / 画像 から選択。画像はファイル選択ダイアログから取り込み
表示拡大・縮小・100% に戻す
プロファイル追加、名前変更、色変更、削除、プロファイルで新しいタブを開く
設定ファイルconfig.json をメモ帳で開く

背景画像

  • 対応形式: jpg / jpeg / png / gif / webp / bmp、20MB まで
  • 取り込んだ画像は %LocalAppData%\XBrowser\StartBg にコピーされます (元のファイルは変更されません)
  • 画像を選び直すと古い画像は自動で削除されます。「画像を削除」で白または黒の背景に戻ります

X の画面にもテーマを反映

オンにすると、アプリのテーマに合わせて X の表示設定 (クッキー night_mode: 0 = ライト、2 = ライツアウト) を書き換えてページを再読み込みします。無限に再読み込みしないよう、同じ目標値に対しては 1 回だけ試みます。

うまく切り替わらないときX 側の仕様変更により効かない場合があります。その場合はこの項目をオフにして、X の「表示」設定で手動で変えてください。
