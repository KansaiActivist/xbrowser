ビルド方法

Go だけでビルドできます。

Windows でビルド

cd xbrowser
go build -ldflags="-H windowsgui" -o xbrowser.exe .

-H windowsgui を付けるとコンソールウィンドウが出ません。外すとコンソール付きで起動します。同梱の go.mod / go.sum で動作確認済みなので、通常は go mod tidy は不要です。

Linux などからのクロスビルド

export GOOS=windows GOARCH=amd64 GOFLAGS=-mod=mod GOPROXY=direct
go build -ldflags="-H windowsgui" -o xbrowser.exe .

アイコンの埋め込み (go-winres)

go install github.com/tc-hib/go-winres@latest
go-winres init
go-winres make
go build -ldflags="-H windowsgui" -o xbrowser.exe .

go-winres make が出力する rsrc_windows_amd64.syso をソースと同じフォルダに置いてからビルドしてください。アプリは実行ファイル内のアイコンリソース (ID 1 → 名前 APP → 最初に見つかったもの) の順で読み込み、タスクバーとタイトルに適用します。

アイコンが変わらないときexe を作り直しても Windows のアイコンキャッシュが古いまま残ることがあります。exe の名前を変える、またはタスクバーのピン留めを外して付け直すと反映されます。debug.log の「アイコン リソース数」で、リソースが埋め込まれているか確認できます。
