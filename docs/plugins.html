プラグイン

JavaScript / CSS をフォルダーに置くだけでページへ機能を追加できます。同梱の sns-hub は Bluesky・Threads・Mastodon などをアプリ内のタブで開けるようにします。

インストール

  1. 設定 →「プラグイン」→「プラグインフォルダーを開く」を押します(%LocalAppData%\XBrowser\plugins。実行ファイルの隣の plugins フォルダーも読み込みます)。
  2. プラグインのフォルダー(中に plugin.json)をそのまま置きます。
  3. 「再読み込み」を押し、新しくタブを開くと反映されます。オン・オフも同じ画面から切り替えられます。

plugin.json

{
  "id": "my-plugin",
  "name": "My Plugin",
  "version": "1.0.0",
  "description": "説明",
  "matches": ["x.com"],
  "allowHosts": ["example.social"],
  "js": ["main.js"],
  "css": ["style.css"],
  "config": { "好きな設定": 1 }
}
項目内容
id必須。英小文字・数字・-・_、40文字まで
matches実行するホスト。空なら、アプリ内で開けるすべてのサイト。サブドメインを含む
allowHostsこのプラグインを有効にすると、アプリ内のタブで開くサイトに加えるホスト。それ以外の外部サイトは従来どおり既定のブラウザーで開く
js / cssプラグインフォルダー内の相対パス(各512KBまで、合計2MBまで)
config自由なJSON。スクリプトから xb.config で読める

スクリプトから使える xb

名前内容
xb.id / name / version / host / lang / isXプラグイン情報、表示中のホスト、言語、Xのページかどうか
xb.configplugin.json の config
xb.css(text)CSSを追加
xb.onReady(fn)DOMの準備ができたら実行
xb.storage.get / set / removeプラグインごとの保存領域(サイトごと・プロファイルごと)
xb.openTab(url)アプリ内の新しいタブで開く(アプリ内で開けるサイトのみ)
xb.openExternal(url)既定のブラウザーで開く
xb.isAllowedHost(host)アプリ内で開けるホストか

スクリプトはページの読み込み時(document-start)に、トップのフレームだけで実行されます。プラグインごとに別のスクリプトとして登録するため、あるプラグインに構文エラーがあっても他には影響しません。

同梱: sns-hub

画面左下のボタンから Bluesky・Threads・Mastodon・Misskey・Instagram・Facebook・Reddit・TikTok・LinkedIn・Tumblr・Pinterest・YouTube・X を開きます。ログイン状態はプロファイルごとに保持されます。サイトを足すときは plugin.json の config.sites と allowHosts の両方に追記してください(例: 別の Mastodon サーバー)。ボタンを右下にするには "position": "right" にします。

Google などの外部ログインを使うサイトは、ログイン用のホスト(例: accounts.google.com)を allowHosts に足さないと、ログイン画面が既定のブラウザーで開いてしまいます。

安全のために

  • プラグインは対象サイトのページ内で自由にスクリプトを実行できます。信頼できるものだけを入れてください。
  • allowHosts には co.jp のような公開サフィックスや IP アドレスは指定できません。
  • プラグインフォルダー外のファイル、シンボリックリンク経由のファイルは読み込みません。
  • プラグインは https のページでだけ動作します。
