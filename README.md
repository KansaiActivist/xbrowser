# xbrowser

X (旧Twitter) 専用の軽量Windowsデスクトップアプリです。Go言語 + WebView2で作られており、
Chromiumをまるごと同梱するElectron系アプリとは違い、Windowsに入っている
Microsoft Edge WebView2 ランタイムを共有して使うため、メモリ消費が小さく済みます。

## 主な機能

* タブ形式のUI(タブの追加・切り替え・閉じる、+ボタンで新規タブ)
* 枠なしのカスタムタイトルバー。最小化/最大化/閉じるボタンはChromeに寄せた
46px幅の大きめサイズ(`window.go` の `winBtnW` で調整可能)
* X (`x.com` / `twitter.com` / `twimg.com`) 以外へのリンクは
自動的にOSの既定のブラウザーで開く(`t.co` の短縮URLも既定のブラウザーで開きます。ページに注入したJavaScriptでクリックと
`window.open` を横取りしています。`inject.go` 参照)
* ウィンドウの端をドラッグしてリサイズ、タイトルバーをダブルクリックで最大化、
Windowsのタスクバーからの最大化にも対応

## 必要環境

* Windows 10 / 11
* [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)
(Windows 11やEdge搭載環境ではほぼ標準で入っています。無い場合はインストールが必要です)
* ビルドには Go 1.21 以降 (Windows上でビルドしてください。CGoは不要です)

## ビルド方法

```powershell
cd xbrowser
go mod tidy
go build -o xbrowser.exe .
```

`go mod tidy` が依存パッケージ (`github.com/jchv/go-webview2`, `github.com/lxn/win`)
を自動取得します。このリポジトリには動作確認済みの `go.mod` / `go.sum` を
同梱しているので、`go mod tidy` を実行しなくても `go build` だけで通るはずです
(実際にWindows向けクロスビルドしてコンパイルが通ることを確認済みです)。
ビルドが終わったら `xbrowser.exe` をダブルクリックで起動できます。

コンソールウィンドウを表示したくない場合は以下でビルドしてください。

```powershell
go build -ldflags="-H windowsgui" -o xbrowser.exe .
```

## 仕組み(構成ファイル)

|ファイル|役割|
|-|-|
|`main.go`|ウィンドウクラス登録・メッセージループ|
|`window.go`|タイトルバー/タブ/ボタンのレイアウトとクリック判定(ヒットテスト)、ドラッグ移動・リサイズ|
|`paint.go`|GDIによるタイトルバー・タブの描画|
|`tabs.go`|タブごとにWebView2コントローラ(`edge.Chromium`)を1つ作って埋め込む|
|`inject.go`|各タブに注入するJavaScript(外部リンク検知・タイトル通知)|
|`external.go`|既定のブラウザーでURLを開く処理|

タブはそれぞれ別のWebView2コントローラを持ちますが、`DataPath`
(`%LocalAppData%\\XBrowser\\WebView2Data`)を共有しているので、裏側のEdgeの
ブラウザプロセス・ログインセッションは1つにまとまります。これにより
「タブごとに1つのChromiumプロセス」を起動するアプリよりメモリ効率が良くなっています。

## 既知の制限・カスタマイズしやすい点

* **外部リンク判定はクリック/`window.open`ベース**です。
サーバー側リダイレクトで外部サイトへ飛ぶケースなど、ページ内の
JavaScriptによる `location.href = ...` 型の遷移は検知できない場合があります。
より厳密にしたい場合は WebView2 の `NavigationStarting` イベント
(COMレベルのAPI)をフックする実装への拡張が必要です。
* レイアウトは固定ピクセルで、DPIスケーリング(拡大表示設定)には
簡易対応のみです。高DPI環境で見た目を合わせたい場合は `window.go` の
定数(`titleBarH`, `winBtnW` など)をDPI倍率に応じて調整してください。
* タブを閉じる際、WebView2コントローラの明示的な破棄処理までは行って
いません(子ウィンドウの破棄に任せています)。実運用で長時間・大量に
タブを開閉する場合は、より丁寧なクリーンアップの追加を検討してください。
* アイコンは既定のアプリケーションアイコンです。`main.go` の
`win.LoadIcon` を `.ico` リソースの読み込みに差し替えると独自アイコンに
できます。

## 修正履歴

* Win32のメッセージループとWebView2(COM)は同じOSスレッドで動く必要があるため、
`main.go` の先頭で `runtime.LockOSThread()` を呼ぶようにしました。これが
抜けているとGoのgoroutineスケジューラの都合でWebView2の初期化が不安定になり、
ページが表示されないことがあります。
* 枠なしウィンドウ(`WS\_CAPTION`無し)を最大化すると、Windowsが持つ「見えない
リサイズ枠」の分だけ画面端からはみ出す既知の問題があるため、`WM\_NCCALCSIZE`
で最大化時のクライアント矩形を補正するようにしました(`WM\_GETMINMAXINFO`の
ワークエリア補正と合わせて使うことで正しく画面いっぱいに最大化されます)。
* 最小化時にタブの中身を無駄にリサイズしないようにしました。
* 最初のタブがサイズ0の状態で初期化されないよう、タブ作成前にコンテンツ領域を
確定させるようにしました。
* **「タブの中に、飾り気のない別の小さなウィンドウ(最小化/最大化/閉じるボタン
付き)が浮いて出てくる」不具合を修正。** WebView2は、アプリ側が
`NewWindowRequested` を処理しないと、`window.open()` や
`target="\_blank"` のリンクをクリックしたときに既定の飾り気のない
ポップアップウィンドウを勝手に開いてしまいます。`inject.go` の注入JSを
修正し、X自身のドメイン宛でも新しいネイティブウィンドウを一切開かせず、
必ず同じタブの中で遷移するようにしました(外部ドメインは従来どおりOSの
既定のブラウザーへ)。おそらくX.com側が読み込み時に何かをポップアップで
開こうとしていたのが、真っ黒な浮いたウィンドウの正体だったと考えられます。
* **画面が真っ黒になる不具合の対策。** WebView2はページ読み込み前後に既定の
背景色が黒になることがあり、これが「何も表示されない」ように見える一因に
なります。WebView2コントローラの既定の背景色を明示的に白に設定するように
しました(`tabs.go` の `PutDefaultBackgroundColor`)。
* **多重起動の防止を追加しました。** WebView2は同じユーザーデータフォルダを
複数プロセスで同時に使えないため、xbrowser.exeを2つ同時に起動すると
片方(または両方)が固まることがあります。すでに起動している場合、
2つ目のプロセスは新しいウィンドウを作らずに既存のウィンドウを前面に
出すだけにしました。画面が変化せず「動いていないのでは」ともう一度
exeを起動してしまうとこの状態になりやすいので、直らない場合はまず
タスクマネージャーで `xbrowser.exe` が複数動いていないか確認し、
すべて終了させてから1つだけ起動し直してみてください。
* コンソールの無いGUIアプリでも状況を追えるよう、
`%LocalAppData%\\XBrowser\\debug.log` にWebView2初期化・ページ読み込み・
注入JSからの通知などの簡単なログを出力するようにしました。それでも
症状が直らない場合は、このログの内容を教えてもらえると原因を特定
しやすくなります。

### 既知の残課題

上のJS側の対策は、通常のクリックや `window.open()` はすべて捕捉しますが、
**中クリック(ホイールクリック)や Ctrl+クリックで新しいウィンドウを開こうと
した場合** は、WebView2内部の挙動を直接横取りする `NewWindowRequested` という
より低レベルなAPI対応が別途必要です(現時点では未対応です)。もしこのケースで
まだ同じ症状(飾り気のない小さいウィンドウが浮く)が起きるようであれば教えて
ください。追加で対応します。

## 拡大・縮小と見た目のカスタマイズ

**拡大・縮小**

* `Ctrl` + マウスホイール、`Ctrl` + `+` / `-` / `0`(100%に戻す)
* タブバー右側の「縮小 / 100% / 拡大」ボタン(中央の%をクリックで100%に戻る)
* 拡大率は `config.json` に保存され、次回起動時も引き継がれます(25%〜500%)。

**右クリックメニューから設定**
タブバー上(タブや余白)を右クリックすると、次のメニューが出ます。

* 設定 → テーマ(ダーク/ライト)、色を編集(色ごとにカラーピッカーが開きます)、
角の丸み、色を初期値に戻す、設定ファイル(config.json)を開く
* 新しいタブ / このタブを閉じる / 拡大率を100%に戻す

変更は `config.json` に自動保存され、その場でタブバーに反映されます。
(ページ内の右クリックはWebView2標準のメニューのままです。)

**タブ・ボタンの色や丸み(ファイルで直接編集する場合)**
`%LocalAppData%\\XBrowser\\config.json` を編集してアプリを再起動すると反映されます
(初回起動時に自動で作られます)。

```json
{
  "zoom": 1,
  "theme": {
    "preset": "dark",
    "barBackground": "",
    "tabActive": "#2F3336",
    "tabRadius": 14
  }
}
```

* `preset` は `"dark"`(Xの黒に馴染む配色)または `"light"`。
* 色は `#RRGGBB` 形式。空文字 `""` の項目はプリセットの色が使われます。
* 指定できる項目: `barBackground` `tabActive` `tabInactive` `tabHover` `tabText`
`tabTextInactive` `icon` `buttonHover` `closeHover` `closeHoverIcon`、
角の丸み `tabRadius`(px、既定12)。
* 拡大縮小のボタンやウィンドウボタンのアイコンは、Windows標準のアイコンフォント
(Segoe MDL2 Assets)で描いているため、拡大しても崩れません。

## 追記の修正(最大化・上部が白くなる問題)

* 「最大化で起動」するショートカットなどで、起動直後の最大化がずれたまま
(端をクリックすると直る)になる問題を修正しました。ウィンドウ枠の補正処理が、
アプリの準備が整う前は無効になっていたのが原因でした。また、最大化中は
クライアント領域をそのモニターのワークエリアに固定する方式に変更しました
(以前は補正が二重にかかり、周囲に隙間が出ることがありました)。
* 他のウィンドウを開いた/切り替えた後に上部が白くなり、クリックすると直る問題に
対して、枠の再描画を止め、アクティブ状態や位置の変化のたびにタブバーを
再描画し、背景も白ではなくバーの色で塗るようにしました。

## 右クリックメニュー・通知設定・最大化のさらなる修正

* **右クリックメニューに「設定」を追加しました。** タブバー上を右クリックすると、
新しいタブ/タブを閉じるに加えて「設定」サブメニューが出ます。ここから
テーマ(ダーク/ライト)の切り替え、色ごとの個別編集(Windows標準の色選択
ダイアログが開きます)、角の丸みの変更、色を初期値に戻す、
config.jsonを直接開く、といった操作ができます。
* **Xのプッシュ通知ON/OFFを追加しました。** 右クリックメニューの「設定」内、
「Xのプッシュ通知」のチェックを切り替えると、その場で全タブに反映されます
(OFFにすると通知の許可ダイアログ自体を出さず、常に拒否した扱いになります)。
設定は `config.json` の `"notifications"` (`"on"`/`"off"`) にも保存されます。
* **最大化でタスクバーが隠れる/起動直後の最大化がぴったり合わない問題への
対策。** ウィンドウ枠を消しているため、Windows標準の計算だけだと最大化時に
タスクバーの領域まで覆ってしまったり、端に触れるまでサイズがずれたままに
なることがありました。最大化時のクライアント領域をモニターの
ワークエリア(タスクバーを除いた領域)に直接合わせる処理と、Windows内部の
最大化計算(`WM\_GETMINMAXINFO`)側でも同じワークエリアに合わせる処理の
両方を入れて、二重に対策しました。
* 起動時の初期ウィンドウ位置も、`CW\_USEDEFAULT`(枠なしウィンドウでは座標が
不安定になることがある)を使うのをやめ、現在のモニターのワークエリアを
基準に中央寄せで計算するようにしました。

## アカウント管理(プロファイル)・アイコン(.syso)の対応

### プロファイルで5個以上のアカウントを管理する

X のWeb版はアカウント切り替えを5個までしか登録できませんが、このアプリでは
タブごとに別の「プロファイル」(Cookie・ログイン状態が完全に独立した入れ物)を
割り当てられるようにしました。プロファイルの数に制限はありません。

* 右クリックメニュー →「プロファイルを選んで新しいタブ」から、プロファイルを
選んで(または「新しいプロファイルを追加…」で名前を付けて)新しいタブを
開けます。
* 右クリックメニュー →「このタブのプロファイル」から、既存のタブが使う
プロファイルを後から切り替えることもできます(タブの中身は同じ位置に
保ったまま、そのプロファイルで開き直します)。
* どのプロファイルを使っているか分かるように、タブに小さな色付きの丸が
表示されます(Defaultには付きません)。
* 各プロファイルのログイン状態は
`%LocalAppData%\\XBrowser\\WebView2Data`(Default)、
`%LocalAppData%\\XBrowser\\WebView2Data-<プロファイル名>`
に、それぞれ独立して保存されます。

### アプリのアイコン(タスクバー)を自分の画像にする

`.syso` ファイル(`favicon.syso` など)を使ってexeにアイコンを埋め込む場合、
**アイコンのリソースIDを `1` にしてください。** アプリ側で自分の実行ファイルの
リソースID 1からアイコンを読み込み、ウィンドウ・タスクバー・Alt+Tabの
すべてに使うようにしてあります(埋め込みが無い場合は、これまでどおり
Windows標準のアイコンにフォールバックします)。

作成には例えば以下のようなツールが使えます(このプロジェクトのフォルダ
直下に出力した `.syso` を置いて `go build` するだけで自動的に埋め込まれます)。

```powershell
# 例: github.com/akavel/rsrc を使う場合
go install github.com/akavel/rsrc@latest
rsrc -ico myicon.ico -o favicon.syso

# 例: github.com/tc-hib/go-winres を使う場合
go install github.com/tc-hib/go-winres@latest
go-winres simply --icon myicon.ico -out favicon.syso
```

どちらのツールも既定でリソースID 1にアイコンを割り当てるので、追加の設定は
不要のはずです。

## 設定タブ・スタートページ

**設定をタブで開く(Xの設定画面風)**

* タブバー右側の歯車ボタン、右クリックメニューの「設定」、または `Ctrl` + `,` で「設定」タブが開きます(すでに開いていればそのタブへ切り替え)。
* 左にカテゴリ一覧と検索、右に内容を表示します(ウィンドウが狭いときはXのスマホ表示のように1画面ずつ切り替わります)。

  * **一般**: 起動時・新しいタブで開く画面(Xの画面 / スタートページ)、Xのプッシュ通知 ON/OFF
  * **外観**: テーマ(ダーク/ライト)、角の丸み、各部分の色(カラーピッカー。選ぶとすぐタブバーに反映)
  * **プロファイル**: 追加・削除・そのプロファイルで新しいタブを開く
  * **表示**: 拡大・縮小
  * **このアプリについて**: config.json の場所と、メモ帳で開くボタン
* これまで右クリックメニューにあった色・テーマ・通知などの項目は、この設定タブへ移しました。

**起動時の画面を選ぶ(スタートページ / Xの画面)**

* 設定 → 一般 →「起動時に開くページ」で選びます。`config.json` の `"startPage"` (`"x"` または `"simple"`) にも保存されます。既定は従来どおり `"x"`(Xの画面)です。
* アプリの起動時と、新しいタブ(＋ボタン・右クリックメニュー・プロファイルを選んだ新規タブ)に適用されます。
* **スタートページ(簡易)** は、時計・Xの検索ボックス・ショートカット(ホーム/話題を検索/通知/メッセージ/ブックマーク/リスト/ポスト作成/設定)だけのシンプルな画面です。選んだ項目はそのタブ(そのプロファイルのログイン状態)のままXのページへ移動します。
* 右クリックメニューの「スタートページを開く」で、設定に関係なくスタートページのタブも開けます。

設定タブ・スタートページはアプリに埋め込んだローカルHTML(`pages/settings.html`, `pages/start.html`)で、通常のタブと同じWebView2を使うため、追加のメモリ消費はほとんどありません。

## 表示言語・スタートページの背景

**表示言語(日本語 / English / 简体中文 / 한국어)**

* 設定 → 言語 で選びます。メニュー・設定画面・スタートページ・ダイアログ・タブ見出しなど、アプリ全体の表示がすぐに切り替わります。`config.json` の `"language"`(`ja` / `en` / `zh` / `ko`)に保存されます。
* 初回起動(設定ファイルがまだ無いとき)だけ、Windowsの表示言語から自動で選びます(日本語・中国語・韓国語以外は英語)。以前からの設定ファイルをお持ちの場合は、これまでどおり日本語のままです。
* 文言は、アプリ本体(メニューなど)が `i18n.go`、設定画面とスタートページが `pages/i18n.js` にあります。言語を増やす・文言を直すときはこの2つを編集してください。

**スタートページの背景(白 / 黒 / 画像)**

* 設定 → スタートページ → 背景 で選びます。`config.json` の `"startBg"`(`white` / `black` / `image`)と `"startImage"` に保存されます。
* 既定は、これまでの見た目に合わせて現在のテーマ(ダーク→黒、ライト→白)です。
* 画像は「画像を選ぶ…」から選びます(JPG / PNG / GIF / WebP / BMP、20MBまで)。選んだ画像は `%LocalAppData%\\XBrowser\\StartBg\\` へコピーされるので、元のファイルを移動・削除しても大丈夫です。画像の上の文字や検索ボックスは、読みやすいように暗いフィルター付きで表示されます。
* 「画像を削除」で背景画像を消して、白/黒に戻せます。

## プロファイルの名前変更・色変更

* 設定 → プロファイル で、各プロファイルの **名前を変更** と **色の変更** ができます(Defaultも変更できます)。

  * 名前: 「名前を変更」→ 入力して Enter(または「保存」)。Escで取り消し。30文字まで、他のプロファイルと同じ名前にはできません。
  * 色: 8色のパレットから選ぶか、カラーピッカーで好きな色を選びます。「自動に戻す」で、名前から決まる自動の色に戻ります(Defaultは「色なしに戻す」)。
  * 色はタブ左の丸い目印、右クリックメニュー、スタートページのプロファイル表示にすぐ反映されます。
* **名前を変えてもログイン状態は失われません。** ログイン情報のフォルダは、プロファイルを作ったときの名前(ID)で決まっていて、名前を変えてもそのままです。変わるのは表示名だけです。
* `config.json` には `profileNames`(ID → 表示名)と `profileColors`(ID → `#RRGGBB`)として保存されます。

## 起動時の表示

起動時は最大化された状態で開きます(タスクバーは隠れません)。元のサイズに戻すと、画面の85%ほどの大きさで中央に表示されます。

## アイコンの指定(go-winres / rsrc / .syso)

* exe に埋め込んだアイコンは、リソース名を問わず自動で読み込みます(`go-winres` が使う名前 `APP`、`rsrc` などの整数ID、どれでも可)。ウィンドウ・タスクバー・Alt+Tabのアイコンに使われます。
* 埋め込んだ .syso は **`rsrc\_windows\_amd64.syso` のように `\_windows\_amd64` を付けた名前** で、`main.go` と同じフォルダに置いてください(go-winres の既定の出力名です)。名前が違うと Go が読み込まず、アイコンは付きません。
* 反映されないときは、アイコンキャッシュの影響のことがあります。exe の名前を変える、またはエクスプローラーを再起動してから確認してください。
* `%LocalAppData%\\XBrowser\\debug.log` に、読み込めたアイコンのリソース数が `アイコン リソース数=N` と記録されます(N=0 なら .syso が exe に入っていません)。

## アドレスバー・タブ並び替え・テーマ切替・通知バッジ

**アドレスバー**

* タブの下の段に、戻る/進む/再読み込みとアドレスバーがあります(拡大縮小・テーマ切替・設定ボタンは右端)。`Ctrl` + `L` で入力欄にカーソルが移ります。
* 表示中のページのURLが表示されます(Xのページ内移動にも追従します)。入力して Enter で開きます。

  * Xのドメイン(`x.com` / `twitter.com` など)→ そのタブで開く。`http://` は `https://` に直します。
  * X以外のURLと `t.co` → OSの既定のブラウザーで開く(アプリ内では開きません)。
  * URLでない文字列 → Xの検索結果を開く。`@名前` はそのアカウントのページを開く。
  * スタートページのタブで入力しても、そのタブがXのページに切り替わります。Esc で元の表示に戻ります。

**タブの並び替え**: タブをドラッグして左右に動かすと入れ替わります(ドラッグせずにクリックすれば、これまでどおり切り替えのみ)。

**ダーク/ホワイトの切り替え**

* ツールバー右の太陽/月のボタン、または `Ctrl` + `Shift` + `D` でダークとライトを切り替えます。設定 → 外観 では「システムに合わせる」も選べます(Windowsのアプリのモードに連動し、Windowsの設定を変えると自動で切り替わります)。
* 「Xの画面にも反映」(既定はオン)では、Xの表示設定(クッキー `night\_mode`)を書き換えて再読み込みし、Xの画面もダーク(Lights out)/ライトに合わせます。Xの仕様変更などでうまく切り替わらない場合はオフにして、Xの「表示」設定で変更してください。`config.json` の `themeSync`(`on` / `off`)に保存されます。

**通知バッジ**: 未読の通知・DMの件数を、タブの閉じるボタンの左に赤いバッジで表示します(99件超は `99+`)。XのメニューのバッジとタブのタイトルのXの`(N)`から読み取っているため、Xの画面の作りが変わると件数が出なくなることがあります。
