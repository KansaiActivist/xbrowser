# xbrowser

X (旧Twitter) 専用の軽量Windowsデスクトップアプリです。Go言語 + WebView2で作られており、
Chromiumを丸ごと同梱するElectron系と違い、Windowsに入っている
Microsoft Edge WebView2 ランタイムを共有するため、メモリ消費が小さく済みます。

## 主な機能

- タブ形式のUI(追加・切り替え・閉じる・**ドラッグで並び替え**)と、枠なしのカスタムタイトルバー
- **アドレスバー**(`Ctrl` + `L`)。X以外のURLと `t.co` は既定のブラウザーで開く
- 右クリックで**翻訳**(選択したテキストやポスト本文を、その場のポップアップで翻訳)
- **プロファイル**(ログイン状態が独立した入れ物)で複数アカウントを使い分け。名前・色を変更可能
- 設定は**タブ**として開く(Xの設定画面風)。表示言語は日本語 / English / 简体中文 / 한국어
- ダーク / ライト / システム連動の切り替え(Xの画面にも反映可能)
- **上部バー(タブ・アドレスバー)の大きさと配置**を設定で変更(80〜140%、タブが上 / アドレスバーが上)
- XのリンクはアプリのタブでOPEN(`target="_blank"`・中クリック・Ctrl+クリック・ショートカットの起動引数)
- 簡易スタートページ(背景は白 / 黒 / 画像)
- **他のブラウザーの「Xで共有」をXBrowserで受ける**(付属の拡張機能 + `xbrowser://`)
- 通知バッジ(未読の通知・DM件数)、通知のON/OFF、拡大縮小(25%〜500%)
- 起動時に最大化、多重起動の防止

## 必要環境

- Windows 10 / 11
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)
  (Windows 11やEdge搭載環境ではほぼ標準で入っています。無い場合はインストールが必要です)
- ビルドには Go 1.21 以降 (Windows上でビルドしてください。CGoは不要です)

## ビルド方法

```powershell
cd xbrowser
go build -ldflags="-H windowsgui" -o xbrowser.exe .
```

`-H windowsgui` を付けるとコンソールウィンドウが出ません(外すとコンソール付きで起動します)。
動作確認済みの `go.mod` / `go.sum` を同梱しているので、通常は `go mod tidy` は不要です。
Linuxなどからのクロスビルドは次のとおりです。

```bash
export GOOS=windows GOARCH=amd64 GOFLAGS=-mod=mod GOPROXY=direct
go build -ldflags="-H windowsgui" -o xbrowser.exe .
```

### アイコンの指定(go-winres / rsrc / .syso)

- exe に埋め込んだアイコンは、リソース名を問わず自動で読み込みます(`go-winres` が使う名前 `APP`、
  `rsrc` などの整数ID、どれでも可)。ウィンドウ・タスクバー・Alt+Tabに使われます。
- 埋め込んだ .syso は **`rsrc_windows_amd64.syso` のように `_windows_amd64` を付けた名前** で、
  `main.go` と同じフォルダに置いてください(go-winres の既定の出力名です)。名前が違うとGoが
  読み込まず、アイコンは付きません。
- 反映されないときはアイコンキャッシュの影響のことがあります。exeの名前を変える、または
  エクスプローラーを再起動してから確認してください。
- `%LocalAppData%\XBrowser\debug.log` に `アイコン リソース数=N` と記録されます(N=0なら
  .syso が exe に入っていません)。

## 使い方

**ショートカット**

| キー | 動作 |
|---|---|
| `Ctrl` + `N` | 新しいタブ(現在のタブと同じプロファイル) |
| `Ctrl` + `L` | アドレスバーにフォーカス(`Esc` で元の表示に戻る) |
| `Ctrl` + `,` | 設定タブを開く |
| `Ctrl` + `Shift` + `D` | ダーク/ライトの切り替え |
| `Ctrl` + `+` / `-` / `0`、`Ctrl` + ホイール | 拡大 / 縮小 / 100%に戻す |

**アドレスバー**
- タブの下の段に、戻る/進む/再読み込みとアドレスバーがあります。表示中のページのURLが出て、
  入力して Enter で開きます。
  - Xのドメイン(`x.com` / `twitter.com` など)→ そのタブで開く(`http://` は `https://` に直す)
  - X以外のURLと `t.co` → OSの既定のブラウザーで開く
  - URLでない文字列 → Xの検索結果を開く。`@名前` はそのアカウントのページを開く
  - スタートページや設定のタブで入力した場合、そのタブがXのページに切り替わります

**Xのリンクをアプリで開く**
- ページ内で `target="_blank"` や `window.open`、中クリック、`Ctrl` / `Shift` + クリックで開くXのリンクは、
  ブラウザーを開かず、**同じプロファイルの新しいタブ**で開きます(X以外のURLは従来どおり既定のブラウザー)。
- ショートカットや他のアプリからは、起動引数にURLを渡します。
  例: ショートカットのリンク先を `"C:\...\xbrowser.exe" https://x.com/notifications` にする。
  すでに起動中のときは、新しいウィンドウは作らず、**起動中のアプリに新しいタブとして渡して**前面に出します。
  `x.com/foo` のようにスキームを省いても使えます。Xのドメイン以外の引数は無視します。
- 一度に開けるタブは40個までです。

**他のブラウザーの「Xで共有」を受ける**
Windowsは、`x.com` のリンクだけを特定のアプリで開かせることができません。そこで、(1) アプリが
`xbrowser://` を受け付け、(2) 付属の小さな**ブラウザー拡張機能**が、他のブラウザーで共有ボタン
(`x.com/intent/post` など)を押したときに `xbrowser://share?...` へ切り替える、という組み合わせにしています。
1. 設定 → 一般 → 「他のブラウザーからの共有」をオンにします(現在のユーザーにだけ登録。管理者権限は不要、
   オフにすると削除。アプリの場所を移動したときは、オフ→オンでやり直し)。
2. `extension` フォルダをChrome / Edge(デベロッパー モードで「パッケージ化されていない拡張機能を読み込む」)や
   Firefox(一時的なアドオン)に読み込みます。手順は `extension/README.md` にもあります。
3. 他のブラウザーで共有ボタンを押すと、ブラウザーの確認(「常に許可」で省略可)のあとXBrowserが前面に出て、
   `text` / `url` / `hashtags` / `via` などが入った投稿画面を新しいタブで開きます。
- 手動でも `xbrowser://share?text=こんにちは&url=https%3A%2F%2Fexample.com` や
  `xbrowser://open?url=https%3A%2F%2Fx.com%2Fhome` で開けます(Xのドメイン以外は受け付けません)。
- 投稿はあくまで投稿画面を開くだけで、「ポスト」ボタンはユーザーが押します。

**タブ**: ドラッグして左右に動かすと並び替えできます(ドラッグしなければ、これまでどおり切り替えだけ)。

**翻訳**
- ページ内でテキストを選択して右クリックすると、「コピー / 翻訳」のメニューが出ます。
  ポスト本文の上で(選択せずに)右クリックしたときは、そのポスト全体が対象です。
- 「翻訳」を選ぶと、その場にポップアップが出て翻訳結果を表示します(「コピー」で結果をコピー、
  「Google翻訳で開く」で既定のブラウザーに切り替え、×・Esc・ほかの場所のクリックで閉じる)。
  翻訳先はアプリの表示言語で、翻訳元は自動判定です。
- 翻訳はアプリ本体からGoogleの翻訳サーバー(`translate.googleapis.com`)へ直接問い合わせます。
  選んだテキスト(最大1500文字)はGoogleに送られます。翻訳できなかったとき(通信エラーなど)は、
  ポップアップから「Google翻訳で開く」で代わりに開けます。
- 入力欄の中の右クリックは、これまでどおりWebView2標準のメニューです。

**右クリックメニュー(タブバー)**: XのメニューのUI(丸みのある配色・太めの文字・アイコン、ダーク/ライト連動)に合わせて描画しています。項目は 新しいタブ、プロファイルを選んで新しいタブ、このタブを閉じる、
このタブのプロファイル、選択中のテキストを翻訳、設定、スタートページを開く、拡大率を100%に戻す。

**通知バッジ**: 未読の通知・DMの件数を、タブの閉じるボタンの左に赤いバッジで表示します(99件超は `99+`)。
XのメニューのバッジとタイトルのXの `(N)` から読み取っているため、Xの画面の作りが変わると
件数が出なくなることがあります。

## 設定タブ

タブバー右側の歯車、右クリックメニューの「設定」、または `Ctrl` + `,` で開きます。
変更はすぐ反映され、`config.json` に自動保存されます。

- **一般**: 新しいタブで開くページ(Xの画面 / スタートページ)、通知のON/OFF
- **言語**: 日本語 / English / 简体中文 / 한국어(初回だけWindowsの表示言語から自動で選びます)
- **外観**: ダーク / ライト / システムに合わせる、「Xの画面にも反映」、角の丸み、**上部バー**(大きさ 80〜140%、タブが上 / アドレスバーが上)、各部の色
- **スタートページ**: 背景(白 / 黒 / 画像。JPG・PNG・GIF・WebP・BMP、20MBまで)
- **プロファイル**: 追加・名前変更・色変更・削除・そのプロファイルで新しいタブを開く
- **表示**: 拡大・縮小
- **このアプリについて**: `config.json` の場所と、メモ帳で開くボタン

**ダーク/ライトとXの画面**: 「Xの画面にも反映」(既定はオン)では、Xの表示設定(クッキー
`night_mode`)を書き換えて再読み込みします。Xの仕様変更などでうまく切り替わらない場合は
オフにして、Xの「表示」設定で変更してください。

**背景画像**: 選んだ画像は `%LocalAppData%\XBrowser\StartBg\` にコピーされるので、元のファイルを
移動・削除しても大丈夫です。「画像を削除」で白/黒に戻せます。

## プロファイル

- タブごとに別のプロファイル(Cookie・ログイン状態が完全に独立した入れ物)を割り当てられます。
  Xのアカウント切り替えの上限を超えて使い分けたいときに使えます。数は50個までです。
- 設定 → プロファイル、または右クリックメニューから、プロファイルを選んで新しいタブを開けます。
  既存のタブのプロファイルは、右クリックメニュー「このタブのプロファイル」で後から切り替えられます
  (同じページをそのプロファイルで開き直します)。
- 名前の変更と色の指定ができます(名前は30文字まで、重複不可。色は8色のパレットかカラーピッカー)。
  色はタブ左の丸い目印などに出ます(Defaultは既定で色なし)。
- **名前を変えてもログイン状態は失われません。** ログイン情報のフォルダは作成時の名前(ID)で決まり、
  変わるのは表示名だけです。保存先は次のとおりです。
  - Default: `%LocalAppData%\XBrowser\WebView2Data`
  - その他: `%LocalAppData%\XBrowser\WebView2Data-<プロファイル名>`
    (記号などはフォルダ名では `_` になるため、`a b` と `a_b` のようにフォルダが重なる名前は作れません)
- プロファイルを削除しても、ログイン情報のフォルダは残ります(同じ名前で作り直すと再利用されます)。

## 設定ファイル(config.json)

`%LocalAppData%\XBrowser\config.json` に自動で作られ、設定タブの変更もここに保存されます。
ファイルを直接編集したときは、アプリを再起動してください。

```json
{
  "zoom": 1,
  "notifications": "on",
  "startPage": "x",
  "language": "ja",
  "startBg": "black",
  "themeSync": "on",
  "barScale": 100,
  "barLayout": "tabs-top",
  "theme": { "preset": "dark", "tabActive": "#2F3336", "tabRadius": 14 }
}
```

- `startPage`: `x` / `simple`。`language`: `ja` / `en` / `zh` / `ko`。`startBg`: `white` / `black` / `image`。
- `barScale`: 上部バーの大きさ(80〜140、%)。`barLayout`: `tabs-top`(タブが上)/ `toolbar-top`(アドレスバーが上)。
- `theme.preset`: `dark` / `light` / `system`。色は `#RRGGBB` で、空文字の項目はプリセットの色を使います。
  指定できる項目は `barBackground` `tabActive` `tabInactive` `tabHover` `tabText` `tabTextInactive`
  `icon` `buttonHover` `closeHover` `closeHoverIcon`、角の丸み `tabRadius`(2〜24px、既定12)です。
- `profiles` / `profileNames`(ID → 表示名)/ `profileColors`(ID → `#RRGGBB`)はプロファイルの情報です。

## 仕組み(構成ファイル)

| ファイル | 役割 |
|---|---|
| `main.go` | エントリ(OSスレッド固定、多重起動チェック、ウィンドウ作成、最大化で起動) |
| `window.go` | タイトルバー/タブ/ツールバーのレイアウト、ヒットテスト、ドラッグ移動・リサイズ、タブの並び替え |
| `paint.go` | GDIによるタブバー・アドレスバー・バッジの描画 |
| `tabs.go` | タブごとにWebView2コントローラ(`edge.Chromium`)を作り、ページからのメッセージを処理 |
| `address.go` | アドレスバー(EDITコントロール)と入力の解釈 |
| `inject.go` | 各タブに注入するJavaScript(外部リンク検知、右クリック翻訳、タイトル・URL・バッジ通知) |
| `external.go` / `translate.go` | 既定のブラウザーで開く処理(URLの検証つき) / 翻訳(Googleへの問い合わせと結果の受け渡し) |
| `pages.go` / `pages/` | 設定タブ・スタートページ(埋め込みHTML)とその状態管理 |
| `profiles.go` / `background.go` | プロファイル管理 / スタートページ背景画像 |
| `theme.go` / `config.go` | テーマ(ダーク・ライト・システム連動) / `config.json` の読み書き |
| `i18n.go` / `pages/i18n.js` | 4言語の文言(アプリ本体 / 設定・スタートページ)。言語や文言を直すときはこの2つ |
| `metrics.go` | 上部バーの大きさ・配置(各部のピクセル値をスケールから計算) |
| `protocol.go` / `extension/` | `xbrowser://` の登録と解釈(共有・開く) / 他のブラウザー用の拡張機能 |
| `cmdline.go` | 起動引数のURL、起動中のアプリへの転送(`WM_COPYDATA`)、ページからの「新しいタブで開く」の受付 |
| `menu.go` `inputbox.go` `zoom.go` `icon.go` `debuglog.go` `singleinstance.go` | 右クリックメニュー、入力ダイアログ、拡大縮小、アイコン、ログ、多重起動防止 |

タブはそれぞれ別のWebView2コントローラを持ちますが、同じプロファイルのデータフォルダは共有するので、
裏側のEdgeのブラウザプロセス・ログインセッションは1つにまとまり、メモリ効率が良くなっています。

## セキュリティ上の作り

- ページからアプリへのメッセージは、種類ごとにタブの種類(Xのページ / 設定 / スタートページ)を確かめ、
  大きさや値も検証してから処理します。設定を変える操作は設定タブからしか受け付けません。
- 翻訳の通信はアプリ本体だけが行い、ページ側のJavaScriptからは外部へ通信しません(Xのページに外部通信を許可する必要がありません)。
- `xbrowser://` はどのサイトからも呼べるため、受け付けるのは「共有(`https://x.com/intent/post` を開くだけ)」と「Xのドメインを開く」だけで、受け取る項目と長さも絞っています。
- 「新しいタブで開く」と起動引数・転送されたURLは、Xのドメイン(`https`)だけを受け付け、数と頻度も制限します。
- 既定のブラウザーで開くURLは `http` / `https` だけに限り、`file:` やネットワークパス、
  独自プロトコル、実行ファイルのパスは開きません。短時間の連続オープンも抑えます。
- 外部リンクの判定は、クリック(中クリック・Ctrl+クリックを含む)と `window.open` が対象です。
- 閉じる・最小化・最大化・タブの×は、マウスを**離したとき**に実行します(押した瞬間に実行すると、アプリが消えた後の「離す」操作が背後のウィンドウ=エクスプローラーのタブの×などに届いてしまうため)。
- 設定ファイルは一時ファイル経由で書き込むため、途中で終了しても壊れません。
  `debug.log` は1MBを超えると次回起動時に作り直し、ページから届いたメッセージの中身は記録しません。

## 既知の制限

- `location.href = ...` のようなスクリプトによる遷移や、サーバー側のリダイレクトで外部サイトへ
  移動するケースは検知できません(WebView2の `NavigationStarting` を使う実装への拡張が必要です)。
- レイアウトは固定ピクセルで、高DPIへの対応は簡易的です(`window.go` の定数で調整できます)。
- タブを閉じる際、WebView2コントローラの明示的な破棄はせず、子ウィンドウの破棄に任せています。
- 通知バッジとXの画面へのテーマ反映は、Xの画面構成・クッキーの仕様に依存します。

## トラブルシューティング

- **画面が真っ黒/何も出ない**: WebView2は同じデータフォルダを複数プロセスで使えません。
  タスクマネージャーで `xbrowser.exe` が複数動いていないか確認し、すべて終了してから1つだけ
  起動し直してください。直らない場合は `%LocalAppData%\XBrowser\debug.log` を確認してください。
- **起動時に最大化がずれる/タスクバーが隠れる**: 枠なしウィンドウの最大化は、ワークエリア
  (タスクバーを除いた領域)に合わせて補正しています(`WM_NCCALCSIZE` / `WM_GETMINMAXINFO`)。
